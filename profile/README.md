# DCX Audio

**Equipamentos clássicos, abertos no navegador.**
**Classic gear, open in your browser.**

Aparelhos de áudio no navegador. / Audio machines in the browser.

## Aparelhos / Machines

- [DCX Studio](https://github.com/dcxaudio/dcx-studio): rack com sampler, looper e mixer ligados entre si. / The rack: sampler, looper and mixer that talk to each other.
- [DCX 404](https://github.com/dcxaudio/dcx-404): sampler de performance, 12 pads x 5 bancos, efeitos ao vivo. / Performance sampler.
- [RJ-2000](https://github.com/dcxaudio/rj-2000): sampler e sequenciador de 12 bits. / 12-bit sampler and sequencer.
- [RJ-950](https://github.com/dcxaudio/rj-950): sampler de rack de 12 bits. / 12-bit rack sampler.
- [RJ-42](https://github.com/dcxaudio/rj-42): looper de rack com detecção de BPM. / Rack looper with BPM detection.
- [RJ-1202](https://github.com/dcxaudio/rj-1202): mixer de mesa de 5 canais. / 5-channel desk mixer.

## Apoio / Support

- [dcx-core](https://github.com/dcxaudio/dcx-core): código comum. / Shared code.
- [dcx-design](https://github.com/dcxaudio/dcx-design): painéis, mockups e notas de design. / Panels, mockups and design notes.
- [prototipos](https://github.com/dcxaudio/prototipos): protótipos e experimentos. / Prototypes and experiments.

Projetos independentes, inspirados em equipamentos clássicos; nomes de terceiros aparecem só como referência, sem vínculo com os fabricantes. / Independent projects inspired by classic gear; third-party names are references only, with no affiliation.
